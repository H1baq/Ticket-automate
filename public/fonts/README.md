# Fonts

Self-hosted so the application never calls a third-party font service.

| File                                     | Family         | Licence     |
| ---------------------------------------- | -------------- | ----------- |
| `source-sans-3-latin-wght-normal.woff2`  | Source Sans 3  | SIL OFL 1.1 |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | SIL OFL 1.1 |

Both are variable fonts (Latin subset), taken from the Fontsource packages
`@fontsource-variable/source-sans-3` and `@fontsource-variable/jetbrains-mono`.
